# Functions and equations by their actual expressions

The files in this directory use their **mathematical expressions as UTF-8 filenames**, without an added `.md` suffix. Each file contains Markdown and its own bidirectional bibliography with precise loci. Use **−** for the mathematical minus, **÷** for division, and Unicode super/subscripts where legible. The complete TeX formula lives inside the file, since a filename cannot express every mathematical nuance. Quotient rings use a written `mod` in filenames; **÷** would be misleading there.

There is **one canonical file per distinct mathematical expression and normalization**, not one duplicate per lecture or thesis. Source-local paths like `books/theses/achimescu/equations/...` are real relative Git symlinks to these canonical files. Linked files with source under `companion-paper/` or `background/` are explicitly not claims about an unseen video slide or thesis page.
