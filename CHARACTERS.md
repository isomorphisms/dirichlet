# Generated Dirichlet characters: finite-group engine and C ABI

This is an **arithmetic** module. It is deliberately independent of Wegert
and of modular-form weights. The original seven-character catalogue remains supported by
[draft PR #7](https://github.com/isomorphisms/dirichlet/pull/7).
The generated-character engine also feeds a source-level WebGL2/GLES3 uniform
adapter: the host supplies modulus q, the phase denominator D and the 128
integer residue exponents, with -1 for nonunits. This is shader *source and
headless Chromium* acceptance, not a physical Android/PowerVR qualification.

## The mathematical object

For every positive integer q, a Dirichlet character modulo q is a group
homomorphism

    (Z/qZ)^× -> C^×

extended to all integers by assigning 0 to integers not coprime to q.
Therefore it is periodic, completely multiplicative, normalized to chi(1)=1,
and has modulus 1 on units. The identity character modulo 1 has chi(n)=1
for all integers (including 0, considered as a residue modulo 1).

A character's modulus q, conductor f, value order, and parity are different
invariants. The conductor is the **smallest divisor f of q** through whose
unit-group reduction map the character factors. The principal character
modulo q has conductor 1, but is not the constant-one function on all integers
unless q=1; it vanishes on integers not coprime to q. The parity records
chi(-1)=(-1)^parity. A character modulo q is primitive iff f=q.

The engine represents each residue n by the exact integer exponent e_n of a
common root of unity, or by -1 for a non-unit. For a unit residue,

    chi(n) = exp(2*pi*i * e_n / D),    0 <= e_n < D.

D is the **exponent of the unit group**, not the order of this particular
character. The character value order is

    D / gcd(D, e_n for all unit residues n).

Conductor, parity, normalization, multiplication, and conjugacy of the
coefficients can thus be handled with integers, not with comparisons of
rounded complex numbers. Only numerical evaluation takes cos/sin.

## Complete enumeration, including noncyclic unit groups

Factor q into pairwise-coprime prime powers. For each odd prime power p^a,
the unit group is cyclic of order phi(p^a). The implementation searches a
primitive root and records exact discrete logarithms. For powers of 2:

- q=2: the unit group is trivial;
- q=4: the unit group is C2, generated by -1;
- q=2^a (a>=3): the unit group is C2 x C_(2^(a-2)), generated by -1 and 5.

The Chinese remainder theorem supplies a product of these local groups.
For each cyclic coordinate with generator order d, a character chooses
an integer k in [0,d). All choices are enumerated with the first coordinate
varying fastest. Consequently the number of characters is exactly phi(q).
The common denominator D is the least common multiple of the cyclic orders.
Its exact coefficient on a unit is

    e_n = sum_j k_j * log_j(n) * (D/d_j)  (mod D).

A modulus-one character is handled without a special false generator.

### Examples and independent checks

For q=5, the primitive root 2 gives character indices 1 and 3 with

    chi_plus(1,2,3,4) = (1, +i, -i, -1)
    chi_minus(1,2,3,4) = (1, -i, +i, -1).

For q=8 the cyclic orders are (2,2); index 2 is the quadratic even
character with residues (1,3,5,7) mapped to (1,-1,-1,1).
Index 1 is induced from modulus 4; its conductor is 4, not 8.

For q=15 the local cyclic orders are (2,4), giving 8 distinct characters.
No fake single primitive root for the full noncyclic group is used.

For every divisor f of q, the reduction U(q)->U(f) is surjective. The
character factors through f iff it is trivial on the kernel, equivalently
chi(a)=1 for all units a congruent to 1 modulo f. This gives the conductor
with an exact finite test. (On nonunits the induced character still vanishes.)

## Bounded host implementation

The initial C11 allocation-free struct fixes a **128-residue host limit**
to make a predictable FFI/ABI possible without a heap allocator. The
mathematical construction is general, but **this implementation does not
accept q>128**. Expanding that limit changes the fixed C struct layout and
must be versioned; it should not silently break users of the .so.

- `code/characters.h` — explicit allocation-free C ABI, exact phase
  table, count/generate/verify, finite numerical evaluators.
- `code/characters.c` — complete CRT generator, exact metadata/axiom
  checks and C11 complex evaluation; no C++, Python, or runtime dependency
  beyond libc/libm.
- `web/characters.mjs` — independently written JavaScript generator and
  numeric evaluator, intentionally not a copy of the C implementation.
- `tests/characters-host.c`, `tests/characters.test.mjs` — count all
  characters, reject repeated tables, check axioms and orthogonality,
  conductor/parity, the original seven reference characters and bounds.
- `tests/characters-grid-cli.c` and `tests/characters-cpu-grid.mjs` —
  independent C11/JS comparison of exact metadata and complex values.
- `tests/characters-dlopen.c` — actual Linux dynamic linking and exported
  symbol/struct call checks.
- `web/character-selection.mjs` — maps selected generated-character objects
  to finite numerical probes and a 128-slot integer GLSL uniform table.
- `web/dirichlet.frag.in` — real runtime-generated coefficients via the
  host-provided `u_generated*` uniforms; no shader-side character reimplementation.

Example shared-library build on Linux x86_64:

    cc -std=c11 -O2 -fPIC -shared code/characters.c -lm \
       -o libdirichlet_characters.so

An external C caller can include `characters.h`, allocate a
`struct dirichlet_character`, invoke
`dirichlet_characters_generate(modulus,index,&output)`, and call
`dirichlet_characters_verify(&output)` before use. The portable
`dirichlet_view_set_generated` wrapper admits only such validated tables
and exports the corresponding native GLES3 uniforms. That contract is
suitable for a future Idriç FFI; it does not imply Idriç has already
loaded, typechecked or proved anything about the library.

## Analytic boundary

These finite evaluators are *finite*. For Re(s)>1 the infinite
Dirichlet series and Euler product agree. Nonprincipal character
Dirichlet series converge conditionally in Re(s)>0; principal-character
Dirichlet series converge for Re(s)>1. Principal L-functions have a pole
at s=1, and their finite sums are not analytic continuation.

Do not confuse passing floating-point orthogonality fixtures with a
formal proof. The finite-group *algebraic identities* are checked
exhaustively within the host bound; arbitrary-modulus formalization
in Agda/Idriç, **physical-device** GPU ingestion of generated coefficients,
unbounded construction, analytic continuation, and global L-function
Euler product proofs remain separate work.
