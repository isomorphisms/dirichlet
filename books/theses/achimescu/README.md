# Sever Achimescu — Hilbert Modular Forms of Weight 1/2

**Year:** 2005  
**Source:** [thesis or companion publication](https://thesis.caltech.edu/1520/19/Achimescu-2005.pdf)

The PDF thesis contains theta-series formulas, character-weighted forms, the main span theorem, a concrete real-quadratic example and an elliptic-curve comparison. Weight 1/2 here requires the Hilbert half-integral-weight automorphy factor; it cannot be replaced by naive exponentiation.
